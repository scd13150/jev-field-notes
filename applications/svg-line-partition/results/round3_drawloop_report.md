# 第三轮：画到一半时的判断（循环内，不是画完再整理）

前两轮都在问"这张已经画完的图能不能被读出来"。这一轮问的是另一件事：
**笔还在手里的时候，Jev 能不能参与决策**——这一笔的候选该选哪个、对称的另一边是哪根、
该画的东西是不是漏了、这张里有没有画歪的、下一笔该落哪。

难点马上出现：绘画循环里的判断**没有现成真值**。"这一笔画得好不好"没有标准答案，
人工标注一幅 120 笔的画也要花掉比跑实验多得多的时间。所以这一轮换了个办法：

> **真值由代码造。** 拿真画里已经存在的每一笔，用一组几何扰动生成它的"画错版本"——
> 翻弧、压平、出头、缩放、镜像、平移、折角、拖尾、歪斜。
> 于是"哪一根是原本那一笔"有了一个**构造出来就平衡**的答案，
> 基线不再是前两轮那种"恒定答多数类就能拿 0.4"的偏斜地板，而是**货真价实的 1/K**。
> 同理，"这张里哪一笔被画坏了"也有唯一答案，因为坏的那一笔是我放进去的。

跑的是一个 `pick_shape / pair_mate / presence / spot_fault / next_stroke` 五家族网格：
64 个 state、522 条判定、243,285 输入 tokens、API 侧 53s，`jev-1.13.0`。
按第二轮实测单价折合约 **\$0.010**（一次判断 state 约 2.6k–5.3k tokens，
即 \$0.0001–0.0002；**一千次循环内检查约 \$0.15–0.20**）。

---

## 1. 一句话结论

**在"代码出候选、Jev 挑一个"这个框里，它在画图循环里就能用；在"问它有没有问题"这个框里，它几乎不开口。**

| 实验 | 问的是什么 | 命中 | 1/K 基线 | 置信度 | 读数 |
|---|---|---|---|---|---|
| E1 `pick_shape` | 意图句 + 6 份几何草稿，哪份是原笔 | **0.80** (8/10) | 0.166 | 0.236，**全部落在弃权档** | 强，但置信度完全不能当门用（§3.1） |
| E2 `pair_mate` | 匿名的一笔，右边哪根是它的对称伙伴 | **1.00** (6/6) | 0.200 | 0.755，3 条进 ACT 档全对 | 可以直接落库 |
| E3 `presence` | 抹掉部件之后，那个词的"画了没有"概率 | **AUC 1.00** | 恒定"是"=0.80 | 被抹的词 0.98→0.04–0.22，幸存者 Δ +0.001 | 缺笔检测是免费的 |
| E4 `spot_fault` | 21–24 笔里有一笔是我改坏的，哪笔 | 开放指控 **0.22** / 逐笔 Noul AUC 0.779 | 0.045 | **77.8% 答"都没问题"** | 同一个判别力，换个问法掉 4 倍（§5.1） |
| E5 `next_stroke` | 看了前 N 笔，下一笔落哪 | **0.083** | 0.204 | 0.577，**3 条 ACT 档全错** | 低于随机；且最自信的就是最错的（§5.2） |

三条跨实验的硬规律：

1. **"选"和"找茬"是两件事。** E1 和 E4 喂的是同一批扰动出来的坏草稿，
   让它在 6 个里挑真的：0.80；让它在 24 笔里指出坏的：0.22，剩下 78% 它选择谁都不指控。
   循环里的接口必须是**代码出题、它答题**，不能是"你看看这张有没有问题"。
2. **置信度只在"看得见"的任务上是门。** E2/E3 的置信度与对错同向；
   E5 三条 ≥0.85 的判断**全错**（0.96 说"该画地面线"、0.86 说"该画左眼"，真值分别是 `hair-1`、`leg-1`），
   而唯二答对的那两条只有 0.23 和 0.33。**它自信的是"画家一般会画什么"，不是"这幅画接下来画了什么"。**
3. **它读的是 state 里那几个数字，不是"形状"。** E1 里被拒得最狠的坏草稿是
   `turn_deg` 被压成 0 的压平（拿到 0.028，随机地板 0.164）和长度砍半的收缩（0.047）；
   而保住了长度和转折数的镜像、缩放、折角全都停在随机线上（0.154–0.160）。
   它答对的恰恰是"这个字段被改得不再像一句人话"的那些。

## 2. 怎么做到的

### 2.1 扰动内核：九种"线条会错的方式"

`src/drawloop.py`。每一种都是纯几何的，且**按这一笔自己的尺寸**来改——
把 20px 的嘴放大 1.45 倍只挪 1px，把 240px 的屋顶放大 1.45 倍是 60px，
所以固定像素量的扰动对一半的画是"什么都没发生"，对另一半是"另一幅画"。
`_reach`（自身包围盒对角线）是每一次形变的尺度单位。

| 扰动 | 做什么 | 它毁掉了什么线索 |
|---|---|---|
| `flip_bulge` | 沿自己的弦翻面 | 弧的朝向（表情） |
| `straighten` | 压平成弦 | `turn_deg` → 0 |
| `overshoot` / `shrink` | 绕质心放大 / 缩小 | 长度、与邻笔的比例 |
| `mirror_x` | 绕自身竖直中线翻转 | 手性 |
| `shift` | 整体平移 | 落点 |
| `kink` | 中段顶出一个折角 | 曲率连续 |
| `drift_end` | 自由端挪走、线拖着走 | 端点对齐 |
| `lean` | 绕起点转出角度 | 朝向 |

### 2.2 可见度下限：错要错得肉眼抓得住

`visibility_floor(diag) = max(2.0, 0.10 * diag)`，`diag` 是这一笔自己包围盒的对角线。
低于这个下限的候选**不生成**。这一条改过两次：先用固定 4px，结果 2px 就能把一条嘴的
表情翻掉（对人是明显的错），也能在屋顶上消失（对人是完全看不出来）。
现在每一道小题都带着自己的下限，闸门 `--check` 会断言**每个错误候选的偏差都 ≥ 它自己的下限**，
并且把偏差最小的（也就是最微妙的那些）优先放进选项里。

所以这一轮所有 0.8、1.0 都是在"人眼看得出这是错笔"的前提下读到的，
**不能**外推成"Jev 能看出更细的错"。

### 2.3 防泄漏（真值不能写在题目里）

- 坏草稿和真的那一笔一起打乱后统一重编号 `d-01…d-0N`，**没有** `did="true"` 这种名字；
- E1 把被问的那一笔**从 `state.strokes` 里删掉**，否则它就是表里那个名字对得上的；
- E2 把查询笔匿成 `state.mystery`，同样从表里删掉，否则 `whisker-l1 → whisker-r1`
  是个纯字符串类比题；
- 每家族构造完过一遍 `check_leaks()`，闸门还会断言答案确实在选项里、
  答案槽位在 N 个 state 之间是均匀分布的（否则"永远选第 3 个"就能白拿）。

## 3. 逐实验读数

### E1 `pick_shape`：意图句 + K 份草稿 → 选真的那一笔

`state.intent` 是一句人写的几何意图（嘴："中段往下弯，所以两端比中心高"），
`state.drafts` 是 5–7 份只带几何字段（点列、长度、包围盒、闭合、转折、朝向）的记录。
10 道小题（三幅画各 3–4 个部位），平均 K=6.1。

```
acc 0.800   1/K 0.166   lift +0.634   none-match 0.00   mean_brier 0.085
mean_confidence 0.236   ACT 档 (≥0.85) 0 条   弃权档 (<0.55) 10 条
```

**答错的 2 条**：`hair-1` 选了 `lean`（真笔排第 2）、`smoke-1` 选了 `overshoot`（真笔排第 5）。
两条都不是"蒙了个远的"，而是**恰好栽进 §1 规律 3 里"数字没被改坏"那两类**。

置信度那一行是这一格最该记住的：**80% 正确率，全部落在弃权档，ACT 档一条没有。**
本项目前两轮定的三档门（ACT≥0.85 / CAUTION 0.55–0.85 / 弃权）如果原样搬到这里，
会把 10 条判断全丢掉，包括那 8 条对的。原因也不神秘——6 个选项都是"像那么回事"的形状，
分布本来就摊得平；`p(真)` 在答对的 8 条里是 0.25–0.48，答对完全是 argmax 的事。

> **落地写法：K≤7 的强制选择题，取 argmax，不看 confidence。** 要留人的话，
> 用"真笔的 p 与次高的差"这种**分布内**的量做门槛，不要用厂商那个 confidence。

各扰动被端上去时的平均得票（随机地板 = 1/K ≈ 0.164）：

| 扰动 | n | 平均得票 | 最高 |
|---|---|---|---|
| kink | 1 | 0.160 | 0.16 |
| `mirror_x` | 7 | 0.159 | 0.33 |
| `overshoot` | 7 | 0.154 | 0.30 |
| `lean` | 6 | 0.145 | 0.30 |
| `flip_bulge` | 10 | 0.128 | 0.24 |
| `shift` | 8 | 0.099 | 0.17 |
| `shrink` | 6 | 0.047 | 0.18 |
| `straighten` | 6 | **0.028** | 0.10 |

这就是 §1 规律 3 的原图：只有把数字改到"不像一句人话"的两类（压平→转折 0、收缩→长度减半）
被稳定拒绝，其余五类与随机不可分。

### E2 `pair_mate`：找对称的另一半

火柴人 4 对（arm/hand/leg/foot）、猫 2 对（ear/eye）。查询笔匿成 `state.mystery`，
干扰项从"同类、够得着、但不是它的伙伴"的池子里抽 5 个，K=6。

```
acc 1.000   1/K 0.200   mean_confidence 0.755   ACT 档 3 条全对   mean_brier 0.022
逐条 conf: leg-r 0.97 / arm-r 0.95 / eye-right 0.93 / foot-r 0.79 / hand-r 0.47 / ear-right 0.42
```

6/6，而且选项里就有 `hand-l`、`arm-l` 这种"同部位但同侧"的陷阱——它没有一次被
"名字最像"的答案骗到（本来也没有名字可骗）。低置信的两条是猫耳和手：
那两对的几何差别确实最小（耳朵两个几乎一样的三角形）。

> 这一格是循环里现在就能用的一格：**绑定阶段**（哪根骨架该跟着哪根走）不用人点名，
> 代码把候选摆出来，它给的是带概率的答案，ACT 档可以直接写进 rig。

### E3 `presence`：抹掉部件，看那个词的Probability塌不塌

每幅画抽两个部件（`torso`+`ground` / `wall`+`roof` / `body`+`tail`），
同一批词表在"原画"和"抹掉之后"各问一遍 Noul（"画上还有 X 吗"），10 词 × 3 幅 × 2 条件。

```
抹掉前: mean p = 0.980（30 条全真 → 恒定"是"即满分，这一半只是地板）
抹掉后: p(该有) 0.979  p(被抹) 0.118  AUC 1.000  acc@0.5 1.000  0.4–0.6 弃权 0.000
Δ(被抹) −0.865 / −0.880 / −0.855      Δ(幸存者) +0.001 / +0.001 / −0.001
```

逐词（原画 → 抹掉后）：

| | 被抹的词 | 幸存的词里最动的那个 |
|---|---|---|
| 火柴人 | torso 0.99→0.19，ground 0.99→0.06 | 其余 8 个 Δ ≤ 0.01 |
| 房子 | wall 0.98→0.15，roof 0.98→0.05 | grass 0.94→0.95（+0.01，最大） |
| 猫 | tail 0.98→0.04，body 0.99→**0.22** | fur 0.96→0.95 |

塌下来的幅度就是"它到底看没看这张图"的证据：如果这些概率是从词表先验来的，
抹掉线条不会让 `wall` 掉到 0.15，更不会让旁边 8 个词一动不动。

`body` 只掉到 0.22 而不是 0.05，是这一格最有意思的一条：猫的身体被抹掉之后，
头上、腿上、尾巴的线还在，而**"躯干"这个词本来就靠这些线的位置被推断出来**。
命名越不"唯一对应一根线"的词，塌得越少。这一条对循环里的用法是直接的：
**`tail`、`roof`、`ground` 这种一笔一词的东西，缺笔检测免费；
`body` 这种由一堆笔共同支撑的抽象词，只能量出"变弱"，量不出"消失"。**

### E4 `spot_fault`：一张里放一个坏笔，两问

同一个 state 问两遍：开放指控（Choice，21–24 笔 + "都没问题"），
和逐笔 Noul（"这一笔有没有被画歪"，每笔一条）。18 个 state / 404 条 Noul。

```
开放指控: acc 0.222  vs 1/K 0.045   none-match 0.778   ACT 档 1 条(对)   conf 0.282
逐笔 Noul: AUC 0.779   p(坏) 0.349  p(好) 0.174   弃权 0.005
           acc 0.965 —— 别读，恒定答"没问题"就有 0.955（类别 18:386）
```

按扰动种类拆开，这才是这一格的真读数（`p_fault` = 坏笔的 Noul，`top_clean` = 最好那根干净笔的 Noul）：

| 扰动 | 受害笔 | p_fault | p(干净) | 平均偏差 | 开放指控 |
|---|---|---|---|---|---|
| `straighten` | head / chimney / body-outline | **0.877** | 0.170 | 19.9 | **3/3** |
| `flip_bulge` | mouth / wall-front / head | 0.300 | 0.179 | 45.4 | 1/3 |
| `drift_end` | tail | 0.280 | 0.178 | 3.2 | 0/1 |
| `lean` | arm-r / fence-post-3 / tail | 0.250 | 0.175 | 5.7 | 0/3 |
| `kink` | wall-crack / tail | 0.240 | 0.170 | 2.9 | 0/2 |
| `mirror_x` | leg-l / door-panel / tail | 0.227 | 0.174 | 8.9 | 0/3 |
| `overshoot` | leg-r / sun / body-outline | 0.190 | 0.175 | 10.4 | 0/3 |

四条答中的题，坏笔的 Noul 是 0.53–0.91，**干净笔里最高也只有 0.25–0.30**，
分离是干净的；答不中的 14 题里，坏笔 0.15–0.33 与 `top_clean` 0.26–0.43 **混在一起甚至更低**。
也就是说那 78% 的"都没问题"不是敷衍：它给所有笔的分本来就都在 0.2–0.3 这一带，
**它没有把这一笔区分出来，所以它不指控**。这是诚实的弃权，代价是覆盖率。

而 `flip_bulge` 那一行要说清楚：**平均偏差 45.4px（最大的一类）却只抓到 1/3。**
把一条弧翻面在几何上是这一整轮里最猛的改动，在画上是"表情反了"。
它抓不到，说明 §1 规律 3 的另一个方向：**它判的是"这个数字还像不像这一类笔"，
不是"这个形状在这个位置上对不对"。** 压平会毁掉 `turn_deg`，翻弧什么数字都不毁。

> **落地写法：不要问"这张有没有画歪"，要问"这一笔是不是 `intent` 说的那笔"。**
> 也就是把 E4 拆成 E1：候选由代码生成（上一笔、镜像、缩放），
> 或者候选就是"这一笔的原意图 vs 现在的几何"，强制选。AUC 0.779 说明信号在，
> 0.222 说明开放指控这个框把信号压死了。

### E5 `next_stroke`：看了前 N 笔，下一笔落哪

在第 5/9/13/17 笔处截断，选项 = 真正的那一笔 + 笔尖 travel 最近的 3 根 + 最远的 2 根，
去重后截到 K=5（`pen_travel` 是上一笔终点到候选起点的距离，有方向；平均 K=4.9）。
两个条件：前缀按真实笔顺排 / 前缀打乱。共 24 题。

```
acc 0.083 (2/24)   1/K 0.204   lift −0.121   conf 0.577
ACT 档 3 条，命中 0.000；两条答对的 conf 是 0.23 和 0.33
seen_order 与 shuffled_prefix 各 12 题，acc 都是 0.083，逐 checkpoint 比对：8/12 答案完全相同
代码基线：笔迹最近邻规则 0/12，两个条件都是 0
```

先说基线：**"下一笔就落在笔尖旁边"这条规则在这三幅画上是 0 分**——真值从没出现在
最近邻那一档（真笔的 travel 排名是 2–4，从不为 0，闸门会把这一条逐题打出来）。
因为这三幅画的笔顺是**主题的**（先把地面和身体定住，再回头补头发），不是空间的。
所以这题不是走过场的送分题。

然后 Jev 也没做到：0.083，**低于随机**。而且它答的东西**跟顺序无关**——
前缀按真笔顺排还是打乱，12 个 checkpoint 里 8 个给同一个答案。它给的是：

```
stick@13  → ground   (conf 0.96)  真值 hair-1     "背景画完了，该画地面线了"
cat@13    → eye-left (conf 0.86)  真值 leg-1      "身子有了，该画脸了"
stick@5   → leg-l    (conf 0.78)  真值 arm-l      部位对了，左右错了
stick@9   → leg-r    (conf 0.42)  真值 leg-l      同上，同一处
```

这五条要说得公平一点：**它答的是"画家一般会接着画什么"，题问的是"这幅画的那个人接着画了什么"。**
0.083 里有一部分是这道题的真值本身就不该被当标准答案——作者的个人习惯没有被写进 state，
也不可能被写进去。所以这一格真正的结论不是"Jev 不行"，而是：

> **笔顺不是能从文本里被"预测"出来的信号，它是作者的私有状态。**
> 前两轮的"读顺序"（谁先画：1.00）和这一轮的"猜顺序"（下一笔：低于随机）合起来才是完整的：
> **它能读已经在 state 里的顺序，不能生成不在 state 里的顺序。**
> 循环里要用"下一步"的话，得由代码把作者的意图写成一个显式的待办清单
> （`state.remaining` = 还没画的部件名），而不是指望它看着半成品猜。
> 顺带一条硬约束：**这一族的高置信度是反向指标**，≥0.85 的三条全错。

## 4. 循环里的接口（这轮支持哪一种写法）

把 E1–E4 拼成一次"落笔"的最小闭环，全部是**代码出题**的形状：

```
1 代码：把这一笔的意图写成一句几何陈述（E1 的 `state.intent`）
2 代码：生成 K 份草稿 —— 真候选 + 按可见度下限筛过的扰动（drawloop.make_drafts）
3 Jev ： 一次请求，K 路 Choice 选形状（E1，取 argmax，不看 confidence）+ 对称伙伴 Choice（E2，看 confidence）
4 Jev ： 目标词表上的 Noul 缺笔检查（E3，画完一段再问，0.98→0.15 的塌方就是清单）
5 代码：落笔、更新 stroke 表；每 CHECKPOINTS 笔回到 1
```

一轮 64 state 的代价是 \$0.010，摊到"每笔一次 6 选项判断"是约 **\$0.00018/笔**，
一幅 120 笔的画全程监督 ≈ **\$0.02**。E1 那种 6 选项题**必须**按 argmax 取，
E2 那种绑定题才按 confidence 分档。

## 5. 这轮不能说明什么

- 真值是**我的扰动**造的。E1/E4 量到的是"能不能把代码改过的线和意图分开"，
  这比"这条线画得好不好"低一个数量级。**本轮没有任何一条读数是关于品味的。**
- 所有错误候选的偏差都 ≥ `max(2px, 10%·自身对角线)`。低于这个地板的错，本轮**根本没测**。
- E1 的真那一笔是六个选项里唯一一个"不是别人的仿射变形"——理论上存在一个不需要形状知识
  的取巧解。答错的两条恰好是数字没被改坏的那两类，倾向于说明它没有在用这个取巧解，
  但我没有做对照去排除它。
- 样本量：E1 n=10、E2 n=6、E5 n=24。8/10 的 95% 区间宽到能盖住 0.4–1.0，
  **读方向，不要读小数点**。E4 的 404 条 Noul 是这一轮唯一样本充足的一格。
- E3 的"抹掉前"那一半按定义没有负例（30 条全真），它只是地板，不能单独当成绩；
  AUC 1.00 只来自 6 条负例，方向可信、数值不可信。
- 词表（意图句、部位名、扰动名字）全是本项目给的；问题一律英文。
- 三幅画都是 240–300px 的简单线稿，每个 state 最大 1.4k est tokens。
  **"一幅 120 笔的画要分块问还是整张问"这一轮完全没碰**，所以以上所有读数都来自小 state。
